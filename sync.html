Sync a course folder

Pick the folder you keep a course in and the comparison runs on its own. Every file the LMS has and the folder does not is downloaded straight into the folder. Files already there are left alone, and files of your own that the LMS knows nothing about are ignored. The folder is remembered, so a later sync of the same course takes one click from its Resources page.

Brave turns off the File System Access API, so this page cannot write into your folder. Comparing still works: pick the folder and the missing files arrive as one ZIP in your downloads, ready to extract over it.

To have them written into the folder instead, open brave://flags, search for File System, enable that flag and restart Brave. Chrome and Edge need nothing.
